# User Guide

## Navigate the application

Use the bottom navigation to switch between Home, Academic, Campus and Community. The app bar provides the theme control. The page shell stays consistent while individual services open through embedded web content or a document viewer.

## Academic services

The Academic page groups the timetable, Moodle, enrolment, attendance, Blackboard and academic/exam calendar entry points. Select a service to open its configured destination. Calendar documents use the PDF viewer. Authentication is performed by the destination service where required.

## Campus services

The Campus page groups library, IT, student services and booking/service links. These entries open the corresponding service workflows.

## Community

The Community page embeds the forum. The client adjusts web styling to make the forum fit the app's light/dark appearance. Forum accounts and server content are managed by the deployed community service.

## Home

The landing page presents university information and quick access cards. Its destinations cover events, research, announcements, university stories and policies.
